# ZoomRider-SQL-Analysis

## Project Overview
The goal of this project was to use SQL to clean and analyze ZoonRider trips data ans answer important business question for the manager.*

## Business Questions
- Which city generates the most revenue?
- Which month has the most trips?
- Which vehicle type generates the most revenue?

## Data Cleaning
I cleaned inconsistent city names, identified duplicate trips, and checked missing fare values.

## Key Findings
- **Highest Revenue City: Lagos
- **Busiest Month:  2025-07 
- **Top Vehicle Type: Economy  

## Tools Used
- MySQL
- GitHub

## Conclusion
The analysis provides useful insights into revenue, trip activity, and vehicle performance to help ZoomRide make better business decisions.
